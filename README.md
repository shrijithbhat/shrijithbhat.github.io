# Srijith's Developer Portfolio

Welcome to the source code for my personal developer portfolio website! 

This site is a fully dynamic, single-page application built with React, Vite, and Tailwind CSS. It is designed to showcase my professional experience, featured projects, publications, and technical skills.

## Features

- **JSON-Driven Content**: All the data (experience, education, projects, profile) is dynamically loaded from JSON files located in `src/data/`. Updating the site is as easy as editing a JSON file—no need to touch the UI components!
- **Dark/Light Mode**: Fully responsive, high-contrast themes designed with accessibility and aesthetics in mind.
- **Custom UI Components**: Interactive floating timelines, animated hover states, and smooth scroll navigation.
- **Dynamic Experience Timeline**: The experience section dynamically calculates duration periods and plots them logically against the timeline.

## Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4
- **Deployment**: Configured for standard static site hosting (GitHub Pages, Vercel, Netlify)

## Local Development

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```

Feel free to explore the code!
